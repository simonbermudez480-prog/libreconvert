Output: Módulos de conversión `docxToPdf.ts`, `pdfToDocx.ts`, `index.ts` y worker `converter.worker.ts`.

<task type="auto">
  <name>Task 2: Implementar el motor de conversión PDF a DOCX editable</name>
  <files>lib/converters/pdfToDocx.ts</files>
  <action>
    Crear `lib/converters/pdfToDocx.ts`:
    - Procesar el ArrayBuffer del archivo .pdf utilizando pdfjs-dist.
    - Iterar por cada página del PDF y extraer los elementos de texto (`getTextContent()`).
    - Ordenar los elementos por coordenadas verticales (Y descendente) y horizontales (X ascendente) para reconstruir líneas y párrafos coherentes.
    - Detectar títulos según el tamaño de fuente relativa.
    - Utilizar la biblioteca `docx` para instanciar un `Document`, agregando `Paragraph` y `TextRun` por cada bloque detectado, con saltos de página entre hojas.
    - Empaquetar el documento con `Packer.toBlob(doc)` y retornar el Blob resultante con tipo 'application/vnd.openxmlformats-officedocument.wordprocessingml.document'.
    - Notificar progreso continuo tras procesar cada página.
  </action>
  <verify>Verificar que la función pdfToDocx extraiga texto de PDF y genere un Blob docx válido.</verify>
  <acceptance_criteria>
    - lib/converters/pdfToDocx.ts exporta pdfToDocx(fileBuffer, onProgress).
    - Retorna un Promise<Blob> de formato Word editable.
  </acceptance_criteria>
  <done>Motor PDF a DOCX funcional en cliente.</done>
</task>
