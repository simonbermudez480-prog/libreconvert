<task type="auto">
  <name>Task 1: Desarrollar el motor de extracción tabular PDF a Excel</name>
  <files>lib/converters/pdfToExcel.ts</files>
  <action>
    Crear `lib/converters/pdfToExcel.ts`:
    - Procesar el buffer del PDF con `pdfjs-dist`.
    - Agrupar textos de cada página por filas mediante bandas de tolerancia Y (ej. delta < 5pt).
    - Para cada fila, ordenar las celdas por su coordenada horizontal X para formar las columnas.
    - Construir una matriz de celdas bidimensional `string[][]` (Array of Arrays) por cada página.
    - Utilizar `xlsx` (`XLSX.utils.book_new()`, `XLSX.utils.aoa_to_sheet()`) para crear una pestaña por página o una tabla consolidada.
    - Escribir en formato binario `xlsx` (`XLSX.write(wb, { bookType: 'xlsx', type: 'array' })`) o CSV.
    - Retornar un `Blob` con el tipo MIME correspondiente ('application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' o 'text/csv').
  </action>
  <verify>Validar que pdfToExcel retorne un Blob de Excel válido y con estructura tabular.</verify>
  <acceptance_criteria>
    - lib/converters/pdfToExcel.ts exporta pdfToExcel(buffer, format, onProgress).
    - Soporta los formatos 'xlsx' y 'csv'.
  </acceptance_criteria>
  <done>Conversor PDF a Excel funcional en cliente.</done>
</task>
