<task type="auto">
  <name>Task 1: Desarrollar el conversor de PDF a Imágenes (JPG / PNG)</name>
  <files>lib/converters/pdfToImages.ts</files>
  <action>
    Crear `lib/converters/pdfToImages.ts`:
    - Cargar el PDF con `pdfjs-dist`.
    - Iterar por cada página y renderizarla sobre un `<canvas>` con escala 2.0 (para alta nitidez Retina / 300dpi equivalente).
    - Convertir cada canvas a Blob ('image/jpeg' o 'image/png').
    - Si el PDF tiene 1 página: retornar directamente el Blob de la imagen con el nombre correspondiente.
    - Si el PDF tiene 2 o más páginas: utilizar `JSZip` para empaquetar todas las páginas (`pagina-1.jpg`, `pagina-2.jpg`, etc.) y retornar el Blob del archivo ZIP.
    - Emitir actualizaciones de progreso proporcionales a cada página renderizada.
  </action>
  <verify>Verificar que pdfToImages retorne una imagen para 1 página o un zip para multipágina.</verify>
  <acceptance_criteria>
    - lib/converters/pdfToImages.ts exporta pdfToImages(buffer, targetFormat, onProgress).
    - Soporta formatos jpg y png.
  </acceptance_criteria>
  <done>Conversor PDF a Imágenes funcional en cliente.</done>
</task>

<task type="auto">
  <name>Task 2: Desarrollar el conversor de Imágenes a PDF</name>
  <files>lib/converters/imagesToPdf.ts</files>
  <action>
    Crear `lib/converters/imagesToPdf.ts`:
    - Utilizar `pdf-lib` (`PDFDocument.create()`).
    - Decodificar el ArrayBuffer de la imagen (JPG o PNG/WebP).
    - Si es WebP, dibujarla en canvas y convertirla a PNG antes de incrustar.
    - Incrustar la imagen con `doc.embedJpg()` o `doc.embedPng()`.
    - Añadir una página en el PDF con las dimensiones proporcionales a la imagen (manteniendo aspect-ratio o ajustada a A4).
    - Dibujar la imagen centrada y guardar el documento con `doc.save()`.
    - Retornar el Blob PDF resultante de tipo 'application/pdf'.
  </action>
  <verify>Verificar que imagesToPdf genere un Blob PDF válido a partir de una imagen.</verify>
  <acceptance_criteria>
    - lib/converters/imagesToPdf.ts exporta imagesToPdf(buffer, ext, onProgress).
    - Retorna un Promise<Blob> con tipo application/pdf.
  </acceptance_criteria>
  <done>Conversor Imágenes a PDF funcional en cliente.</done>
</task>
